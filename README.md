# Baby-GPT-2
Creamos el esqueleto de un modelo GPT-2 que será entrenado para tareas de categorización

La estructura básica será 
mini-gpt/
├── minigpt/            ← el código del proyecto (un "paquete" de Python)
│   └── __init__.py     ← archivo vacío; le dice a Python que la carpeta es un paquete
├── tests/              ← aquí irán las comprobaciones automáticas
├── requirements.txt
├── .gitignore
└── README.md
